# Codex Usage Bar

여러 Codex 계정의 사용량과 OpenModel 계정의 잔액을 한눈에 확인하는 **macOS 메뉴 막대 앱**입니다. 메뉴 막대의 막대그래프 아이콘을 클릭하면 계정별 한도, 남은 비율, 리셋 시각과 상태를 확인할 수 있습니다.

SwiftUI와 AppKit으로 구현했으며, 현재 버전은 **v0.3.0**입니다.

## 주요 기능

- 버튼으로 Codex / OpenModel 기본 연결 전환, 전환 전 설정 백업과 되돌리기
- 여러 ChatGPT/Codex 계정 등록 및 계정별 독립 로그인
- OpenModel 계정 로그인, 사용 가능 잔액, 오늘·이번 달 비용 및 토큰 조회
- 전체 계정 비교와 개별 계정 상세 보기
- 5시간·주간 한도, 사용한 비율 또는 남은 비율, 리셋 날짜와 카운트다운
- Edu 계정의 개인 월간 크레딧 한도·사용량·남은 비율
- 서버가 제공하는 누적 토큰과 최근 일별 사용량 그래프
- 수동 새로고침과 자동 갱신, 조회 실패 시 마지막 확인 값 유지
- 계정 별칭 변경·순서 변경·재인증·제거
- 메뉴 막대에 표시할 계정 선택과 계정별 주간 잔량 미터
- 이메일 숨김, 메뉴 막대 사용률 표시, 로그인 시 실행
- 내용과 화면 크기에 맞춘 팝오버 높이 조정

`전체`는 계정 비교 화면입니다. 서로 다른 계정의 사용률을 합산한 퍼센트는 표시하지 않습니다. 화면에 공간이 충분하면 모든 계정을 스크롤 없이 표시하며, 공간이 부족하면 먼저 카드 여백을 줄입니다. 그래도 화면 높이를 초과할 때만 스크롤을 사용합니다.

## 실행 환경

| 항목 | 요구 사항 |
| --- | --- |
| 운영체제 | macOS 14 이상 |
| 빌드 도구 | Swift 6 이상과 macOS SDK를 포함한 Xcode 또는 Command Line Tools |
| Codex 사용량 조회 | `codex app-server`를 지원하는 Codex CLI (OpenModel만 사용할 때는 불필요) |
| 자동 검사 | Python 3 — 가짜 CLI 기반 검사에 사용 |

현재 Apple Silicon Mac에서 빌드·실행을 확인했고, Codex CLI **0.147.0**을 기준으로 개발했습니다. 다른 macOS 버전과 Intel Mac은 별도 검증이 필요합니다. 외부 Swift 패키지 의존성은 없습니다.

## 설치 및 실행

### 1. 소스 다운로드

```bash
git clone https://github.com/leehe228/codex-usage-bar.git
cd codex-usage-bar
```

### 2. 도구 준비

Xcode 또는 Command Line Tools를 설치하고 Swift가 실행되는지 확인합니다. Codex CLI도 설치되어 있어야 합니다.

```bash
swift --version
codex --version
```

Codex CLI를 찾지 못하면 앱 설정에서 실행 파일의 절대 경로를 지정할 수 있습니다.

### 3. 앱 빌드

```bash
./Scripts/build.sh
```

빌드 결과는 다음 위치에 생성됩니다.

- `~/Applications/Codex Usage Bar.app`: 실행할 앱
- `dist/Codex Usage Bar.app`: 설치된 앱을 가리키는 심볼릭 링크
- `dist/Codex Usage Bar.zip`: 앱 번들 ZIP

앱과 ZIP은 Git에 포함하지 않으므로 소스를 받은 뒤 빌드해야 합니다. 빌드 스크립트는 로컬 실행용 ad-hoc 서명을 적용합니다. Developer ID 서명과 Apple 공증을 적용한 배포판은 아닙니다.

### 4. 앱 열기

```bash
open "$HOME/Applications/Codex Usage Bar.app"
```

Dock 아이콘 대신 **메뉴 막대의 막대그래프 아이콘**이 표시됩니다. 아이콘을 클릭해 사용량 창을 엽니다.

## 계정 추가

1. 메뉴 막대 아이콘을 클릭하고 **계정 추가**를 누릅니다.
2. `개인`, `연구`, `업무`처럼 알아보기 쉬운 별칭을 입력합니다.
3. **ChatGPT로 로그인**을 누릅니다.
4. 브라우저에서 등록할 계정으로 로그인합니다. 이미 다른 계정으로 로그인되어 있다면 원하는 계정으로 바꿔 진행합니다.
5. 앱으로 돌아와 이메일과 플랜을 확인하고 **확인 후 등록**을 누릅니다.
6. 다른 계정도 같은 방법으로 등록합니다.

계정마다 독립된 인증 저장소를 사용합니다. 기존 Codex 데스크톱 앱이나 기본 `~/.codex` 로그인을 가져오거나 교체하지 않습니다. 같은 사용자·워크스페이스 연결의 중복 등록은 거부합니다.

## Codex / OpenModel 연결 전환

메뉴 막대 창 하단의 **Codex 연결 → Codex / OpenModel** 버튼으로 Codex가 사용할 기본 연결을 바꿀 수 있습니다. **설정 → Codex 연결 전환**에서는 연결별 모델 이름을 입력한 다음 같은 버튼으로 적용합니다.

- **Codex**: 기본 OpenAI 공급자와 기존 Codex 로그인을 사용합니다. 최초 모델 기본값은 `gpt-5.6-sol`입니다. 현재 Codex 설정이 있으면 해당 모델을 기억합니다.
- **OpenModel**: `https://api.openmodel.ai/v1`의 Responses API를 사용합니다. 최초 모델 기본값은 `gpt-6-astra`입니다. 기존 OpenModel 설정이 있으면 해당 모델을 기억합니다. 실제 사용량은 OpenModel API 잔액에서 차감됩니다.
- **API 키 등록/변경**: 설정의 보안 입력란에 OpenModel API 키를 붙여넣고 **키체인에 저장**을 누릅니다. 이미 `codex-openmodel-api-key` 서비스 / `codex` 계정으로 저장한 키가 있으면 그대로 사용합니다. 콘솔 잔액 조회를 위한 OpenModel 계정 로그인과는 별개입니다.

전환은 사용자 설정 `~/.codex/config.toml`에 적용합니다. Usage Bar 실행 환경에 `CODEX_HOME`이 지정돼 있으면 그 폴더를 사용하며 실제 경로를 설정 화면에 표시합니다. 모델과 공급자를 바꾸고 OpenModel 연결 시 해당 공급자 정의를 키체인 인증 방식으로 구성합니다. 프로젝트, MCP, 플러그인 등 나머지 설정과 `auth.json`은 유지합니다. 다른 공급자나 API 키 로그인을 이미 쓰고 있다면 **Codex** 버튼이 ChatGPT 로그인으로 바꾸지는 않습니다. 원하는 구독 계정으로 Codex에 먼저 로그인하세요.

실행 중인 **Codex 데스크톱 앱은 재시작한 뒤 새 작업을 열어 사용**하세요. 이미 실행 중인 작업의 연결을 강제로 바꾸거나 앱을 자동 종료하지 않습니다. CLI는 다음 실행부터 새 기본 설정을 읽지만 `--profile`, `--model`, `-c` 등 명시적 옵션은 우선 적용될 수 있습니다. 이는 사용량 앱에 등록한 계정의 전환 기능과는 별개입니다.

### 백업과 복원

1. 전환 후보를 별도 폴더에 작성하고 설치된 Codex CLI의 `config/read`로 확인합니다. 이 검사는 모델 호출이나 API 비용을 발생시키지 않습니다.
2. 검사 후 원본 파일이 바뀌지 않았는지 확인하고, 전환 직전 원본을 저장한 뒤 원자적으로 교체합니다.
3. **직전 전환 되돌리기**를 누르면 마지막 전환 직전 파일을 그대로 복원합니다. 전환 후 다른 앱에서 설정을 수정했다면 자동 복원은 비활성화되어 최근 변경을 보존합니다.
4. **백업 폴더 열기**에서 `before-*.toml` 원본 기록과 `codex.toml` / `openmodel.toml` 연결별 최근 사본을 확인할 수 있습니다. 사본은 기록용이며, 다음 전환은 최신 활성 파일의 공통 설정을 유지하면서 연결과 모델만 적용합니다.

백업은 지워질 수 있는 임시 폴더 대신 `~/Library/Application Support/CodexUsageBar/CodexConnections/<설정 경로 식별자>/`에 저장합니다. 폴더 권한은 `700`, 파일은 `600`입니다. 백업은 원본 전체를 포함하므로 외부에 공유하지 마세요. 새 API 키는 TOML에 기록하지 않고 macOS 키체인에서 필요할 때 읽습니다. 심볼릭 링크 파일, 지원하지 않는 키 표기 또는 활성 `profile` 설정이 있으면 자동 편집을 중단합니다.

## 사용량 확인

### OpenModel 계정 추가

1. **계정 추가**에서 서비스를 **OpenModel**로 선택하고 별칭을 입력합니다.
2. **OpenModel로 로그인**을 눌러 앱 전용 창의 공식 콘솔에서 로그인합니다. Google 로그인이 동작하지 않으면 **Sign in with verification code**로 이메일 인증 코드를 사용합니다.
3. 앱이 인증 갱신과 잔액·기간별 통계 조회를 확인합니다. 완료되지 않으면 로그인 창 위의 안내를 확인하고 **로그인 완료 확인**을 누릅니다.
4. 계정 확인 화면에서 이메일을 확인하고 **확인 후 등록**을 누릅니다.

등록한 OpenModel 계정은 Codex 계정들과 같은 목록·카드로 표시됩니다. 전체 카드에서는 사용 가능 잔액을 크게 표시하고, 오늘·이번 달 비용과 월간 요청·토큰을 함께 요약합니다. 잔액은 소수 둘째 자리로 간결하게 표시하며 마우스를 올리면 더 정밀한 금액을 확인할 수 있습니다.

상세 화면에서는 **오늘 / 이번 달 / 최근 24시간**을 선택해 사용 비용, 요청 수, 서버 총 토큰과 평균 TPM을 확인합니다. **비용 / 요청 / 토큰** 전환은 모델별 누적 막대 차트와 모델별 금액·건수·비중에 함께 적용됩니다. 오늘·최근 24시간은 시간별, 이번 달은 일별 추이를 표시하며 상위 5개 모델 외의 전체 내역은 콘솔에서 확인할 수 있습니다. 잔액은 기간 선택과 무관한 현재 잔액입니다.

차트와 모델별 집계는 콘솔의 `dashboard/model-usage` 응답을 사용합니다. 조회가 실패하거나 서버가 값을 제공하지 않으면 미제공 상태를 표시하며 사용량 0으로 대체하지 않습니다. 평균 TPM도 서버가 제공하는 경우에만 표시합니다. 입력·출력 토큰은 **이번 달 → 토큰 상세 · 집계 기준**에서 월간 로그를 빠짐없이 집계할 수 있을 때만 표시하며, 최대 2,000건/20페이지를 넘거나 로그 조회가 실패하면 구분 값을 미제공으로 표시합니다. 출력 토큰에는 추론 토큰이 포함됩니다. 요청 로그 합계와 서버 총 토큰은 서로 다른 집계이므로 일치하지 않을 수 있습니다.

잔액과 비용은 USD이며 마이크로달러 원본을 정수로 보관합니다. 사용 가능 잔액은 전체 잔액에서 동결 금액을 뺀 값입니다. 오늘·이번 달은 Mac의 현재 시간대 기준으로 집계하고 상세 화면에 시간대를 표시합니다. 서비스별 탭은 추가하지 않습니다. 고정 총한도가 없는 OpenModel 잔액에는 임의의 비율 막대를 만들지 않으며, 메뉴 막대의 계정별 비율 미터는 Codex 계정만 대상으로 합니다.

일반 모델 호출용 API 키로는 콘솔 잔액 조회 인증을 통과하지 못하므로 계정 로그인을 사용합니다. 로그인 창은 별도 메모리 세션이며 다른 브라우저의 로그인 정보를 가져오지 않습니다. 앱에 등록한 뒤에는 로그인 토큰과 갱신 쿠키를 Keychain에서 읽고, 만료된 토큰은 한 번 갱신해 재시도합니다. 갱신 쿠키도 만료되면 계정 관리에서 재인증해야 합니다. 웹 API는 서비스 변경에 영향을 받을 수 있습니다.

### 공통 조작

- **전체**: 등록된 계정들의 한도와 상태를 비교합니다.
- **계정 탭 또는 카드**: 해당 계정의 상세 한도, 리셋 날짜와 토큰 집계를 확인합니다.
- **새로고침**: 기다리지 않고 조회를 다시 요청합니다.
- **계정 관리 / 설정**: 계정과 표시 방식을 관리합니다.
- **서비스 상태**: OpenAI 상태 페이지를 브라우저로 엽니다.
- **종료**: 메뉴 막대 앱을 종료합니다.

서버가 제공하는 기간에 따라 5시간 한도가 없는 계정은 주간 한도만 표시될 수 있습니다. 미제공 값은 0으로 표시하지 않습니다. 리셋 시각이 지나도 사용률을 임의로 초기화하지 않고 서버의 새 값을 확인합니다.

### Edu 월간 크레딧

Edu 계정은 일반 5시간·주간 한도 아래에 **월간 사용 한도**를 추가로 표시합니다. 총 한도, 사용 크레딧, 비율과 마지막 확인 시각을 자동 갱신합니다. 예를 들어 한도 7,000 크레딧 중 약 2,108을 사용했다면 약 70% 남음으로 표시합니다.

월간 값은 해당 Edu 워크스페이스의 별도 사용량 경로에서 조회합니다. 이 경로는 비공개 웹 API이므로 서버 변경이나 계정 정책에 따라 조회되지 않을 수 있습니다. 실패하면 마지막 확인 값과 실패 표시를 유지하며, 서버가 제공하지 않은 월간 리셋 날짜를 추정하지 않습니다.

### 상태 표시

| 상태 | 의미 / 조치 |
| --- | --- |
| 정상 조회 | 최근 한도 조회에 성공했습니다. |
| 조회 중 | 해당 계정의 정보를 가져오고 있습니다. |
| 한도 도달 | 서버가 반환한 한도 도달 상태 또는 100% 사용 값입니다. 계정 이름 오른쪽에 표시되며 조회 상태와 별도로 나타납니다. |
| 조회 실패 · 이전 값 | 마지막 확인 값을 유지합니다. 새로고침으로 재시도할 수 있습니다. |
| 재인증 필요 | 계정 관리에서 해당 계정의 **재인증**을 진행합니다. |
| 리셋 확인 중 | 리셋 시각이 지나 서버의 새 한도를 확인해야 합니다. |
| 오래된 값 / 확인 필요 | 마지막 조회가 오래되었거나 아직 사용량을 받지 못했습니다. |

일반 조회 실패의 자동 재시도 간격은 1→2→4→8→15분으로 늘어납니다. 인증 실패는 자동 재시도를 중단하고 재인증을 기다립니다. 최대 2개 계정을 동시에 조회합니다.

정상 조회와 조회 중은 계정 카드에서 각각 체크 아이콘과 진행 아이콘으로 간결하게 표시합니다. 아이콘에 포인터를 올리거나 VoiceOver로 선택하면 상태 설명을 확인할 수 있습니다.

## 설정

| 설정 | 동작 |
| --- | --- |
| 메뉴 막대 대표 계정 | 메뉴 막대에 숫자를 표시할 계정을 선택합니다. |
| 메뉴 막대 표시 계정 | 선택한 계정마다 세로 막대 하나를 표시합니다. 계정 순서대로 배치되며 높이는 주간 남은 비율입니다. 주간 한도가 없으면 5시간 한도를 사용합니다. |
| 메뉴 막대에 대표 계정 사용률 표시 | 기본은 아이콘만 표시합니다. 켜면 대표 계정의 사용률도 표시합니다. |
| 자동 갱신 | 수동 또는 1·2·5·15분 간격을 선택합니다. 기본은 5분입니다. |
| 남은 비율로 미터 표시 | 사용한 비율 대신 남은 비율로 미터와 숫자를 표시합니다. |
| GPT-5.3-Codex-Spark 사용량 표시 | 기본은 숨김입니다. 켜면 서버가 제공한 Spark 한도가 상세 화면에 나타납니다. |
| 이메일 가리기 | 사용량 상세 화면의 이메일을 숨깁니다. |
| 로그인 시 실행 | macOS 로그인 후 앱을 자동 실행합니다. |
| Codex CLI | 자동 검색하거나 실행 파일의 절대 경로를 지정합니다. |

표시 설정은 변경 시 저장됩니다. CLI 경로를 직접 입력했다면 **저장**을 누릅니다. `gpt-reserve`, 범용 남은 크레딧과 리셋 크레딧 행은 숨기며 Edu 월간 한도는 별도로 표시합니다.

계정 관리에서 별칭을 변경한 뒤 **이름 저장**을 누릅니다. 위·아래 버튼으로 순서를 바꿀 수 있습니다. 재인증할 때는 기존과 같은 사용자·워크스페이스로 로그인해야 합니다. 제거는 확인 후 해당 앱 전용 계정 저장소를 삭제합니다.

## 문제가 발생할 때

- **앱 아이콘을 찾을 수 없음**: Dock이 아닌 macOS 메뉴 막대를 확인합니다. 설치된 앱을 다시 열어보세요.
- **Codex CLI를 찾을 수 없음**: CLI 설치 상태를 확인하고 설정에서 실행 파일을 지정합니다. `~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin` 등의 경로를 자동 검색합니다.
- **로그인이 완료되지 않음**: 브라우저에서 원하는 계정으로 승인했는지 확인합니다. 로그인 창의 페이지 다시 열기 또는 취소 후 재시도를 사용합니다.
- **CLI 기능 지원 오류**: `codex app-server`의 로그인·사용량 조회를 지원하는 CLI 버전인지 확인합니다.
- **이전 값이 표시됨**: 새로고침을 누르고, 재인증 필요 상태라면 계정 관리에서 재인증합니다.
- **Edu 월간 조회만 실패함**: 일반 한도와 월간 크레딧은 별도 조회입니다. 일반 한도를 계속 확인할 수 있으며 월간 항목은 마지막 확인 시각을 함께 확인합니다.
- **OpenModel 재인증 필요**: 계정 관리의 재인증을 눌러 기존과 같은 OpenModel 계정으로 로그인합니다. 추가 API 키를 만들 필요는 없습니다.
- **OpenModel 인증 정보 저장 실패**: macOS Keychain 접근 허용 여부를 확인합니다. 다른 Mac에 앱을 복사한 경우 새 Mac에서 다시 로그인합니다.
- **빌드 도구 오류**: 올바른 Xcode/Command Line Tools와 macOS SDK를 선택했는지 확인합니다. 필요한 경우 아래 환경 변수로 경로를 지정합니다.

## 개발 및 검사

현재 사용자 설정의 **복사본**으로 전환과 복원을 검사하려면 아래와 같이 실행합니다. 원본 설정은 변경하지 않으며 모델 API도 호출하지 않습니다.

```bash
CODEX_USAGE_TEST_CONNECTION_CONFIG="$HOME/.codex/config.toml" ./Scripts/test.sh
```


```bash
./Scripts/test.sh
```

기본 검사는 임시 저장소·가짜 CLI·HTTP 응답 대역을 사용하며 실제 계정 로그인이나 원격 사용량 조회를 수행하지 않습니다. Codex CLI가 설치돼 있으면 임시 설정으로 양쪽 공급자의 설정 읽기 및 전환·복원을 추가 검사합니다. OpenModel 검사에는 기존 계정 호환성, 금액 정밀도, 시간대 경계, 쿠키 범위, 인증 갱신/실패, 계정 불일치, 불완전 로그 처리가 포함됩니다. 빈 임시 인증 홈으로 실제 CLI의 요청 규격도 검사하려면 실행 파일을 지정합니다.

```bash
CODEX_USAGE_CONTRACT_CLI="$(command -v codex)" ./Scripts/test.sh
```

앱 빌드 위치와 도구 선택은 다음 환경 변수로 조정할 수 있습니다.

| 환경 변수 | 용도 |
| --- | --- |
| `CODEX_USAGE_APP_DIR` | 앱 설치 폴더 변경. 기본은 `~/Applications`입니다. |
| `DEVELOPER_DIR` | 사용할 Xcode 또는 Command Line Tools 경로 지정 |
| `CODEX_USAGE_SDK` | 사용할 macOS SDK 절대 경로 지정 |

`./Scripts/build.sh --debug`로 디버그 앱을 빌드할 수 있습니다. Command Line Tools에 SDK 26.5가 설치되어 있으면 해당 SDK를 우선 사용합니다. 빌드는 임시 폴더에서 서명한 뒤 앱을 설치하여 파일 동기화 메타데이터로 인한 서명 오류를 줄입니다. 스크립트가 Xcode 라이선스를 승인하거나 시스템의 개발 도구 선택을 변경하지는 않습니다.

실계정과 통신하지 않는 샘플 4계정 미리보기:

```bash
open -n "$HOME/Applications/Codex Usage Bar.app" --args --demo --show
```

`--demo --preview-window`는 같은 사용량 화면을 확인용 창에 표시합니다. 운영 앱과 미리보기를 동시에 열면 아이콘이 두 개 생기므로 미리보기의 **종료**로 정리합니다.

## 데이터와 인증 저장

앱 데이터는 `~/Library/Application Support/CodexUsageBar/`에 저장됩니다.

- `accounts.json`: 계정 별칭·이메일·플랜·설정과 최근 사용량
- `accounts/<UUID>/auth.json`: 계정별 인증 정보. Codex CLI가 저장·갱신합니다.
- macOS Keychain의 `com.hoeun.codex-usage-bar.openmodel`: OpenModel 계정 UUID별 로그인 토큰·갱신 쿠키. 계정 JSON과 ZIP에는 포함되지 않습니다. 앱에서 계정을 제거하면 해당 Keychain 항목도 삭제합니다.

디렉터리와 인증 파일 권한은 각각 0700과 0600으로 제한합니다. 인증 파일은 비밀번호처럼 취급해야 하며 공유하거나 Git에 넣지 않습니다. 앱은 토큰이나 원문 stderr를 진단에 출력하지 않습니다. 사용량 확인만 수행하며 작업 실행이나 리셋 크레딧 소비는 하지 않습니다.
